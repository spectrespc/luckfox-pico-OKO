Import configuration

The configuration is stored in /userdata/vpn and applied by /usr/bin/oko-vpn. Script hooks (PreUp/PostUp/PreDown/PostDown) are rejected; the default route is only replaced for 0.0.0.0/0 with an automatic rollback.

Web access

HTTP Basic authentication: there is no log-out and no HTTPS. The password is sent with every request and stored in divinus.yaml in plain text.

Export Export log

Maintenance

Restarting the streamer drops the video streams for a few seconds. Rebooting the device takes about half a minute.

Controller firmware –

The daemon is stopped while the controller is flashed. Do not power off the device. The version comes from the file name: app-1.0.1.bin, app-2.0.1.ihx.
